# VELO LEAGUE

Klickbarer Frontend-Prototyp für eine soziale Rennrad-Wettkampfplattform.

## Starten

```bash
pnpm install
pnpm dev
```

Anschließend die von Vite ausgegebene lokale Adresse im Browser öffnen.

## Produktion prüfen

```bash
pnpm run build
```

Die Oberfläche verwendet lokale Mock-Daten in `src/data/mockData.ts`. Seiten und wiederverwendbare Bausteine sind getrennt in `src/pages` und `src/components` abgelegt.
